# Локальный RAG-ассистент

Ассистент для работы с учебными материалами: находит подходящие фрагменты лекций,
отвечает на вопросы и указывает источники. Проект включает терминальный чат,
API и инструменты для сравнения качества разных вариантов RAG.

После загрузки зависимостей и моделей обработка документов и генерация ответов
выполняются локально, без обращения к облачным LLM.

## Возможности

- Документы PDF, DOCX, PPTX, TXT и Markdown.
- Поиск по смыслу, гибридный поиск и дополнительное ранжирование фрагментов.
- Ответы локальных моделей через Ollama со ссылками на использованные материалы.
- Терминальный чат с выбором модели и просмотром источников.
- HTTP API для подключения других приложений.
- Четыре эксперимента с сохранением ответов, расчётом метрик и построением графиков.

## Запуск

Нужны **Python 3.13**, **uv** и **Ollama**. Объём памяти зависит от выбранной модели;
загружать весь набор моделей для работы с чатом не требуется.

Из корня проекта:

```bash
cd local_rag_service
uv sync --frozen --python 3.13
```

При необходимости скопируйте `.env.example` в `.env` и измените настройки.
Запустите Ollama и подготовьте модели на машине с доступом к интернету:

```bash
ollama pull qwen3.5:9b
uv run --frozen python prepare_models.py
```

Поместите документы в `local_rag_service/data/raw/`, затем запустите чат:

```bash
uv run --frozen python chat.py --model qwen3.5:9b --ingest
```

Первый запуск обработает документы и построит индекс. Для повторного запуска
с теми же документами уберите `--ingest`. В чате доступны команды `/models`,
`/model ИМЯ`, `/sources`, `/ingest`, `/help` и `/exit`.
Каждый вопрос обрабатывается независимо: история диалога модели не передаётся.

API запускается отдельно:

```bash
uv run --frozen uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Описание и интерактивная проверка API: `http://127.0.0.1:8000/docs`.

## Эксперименты

| Эксперимент | Что сравнивается |
| --- | --- |
| 1 | Способы разбиения документов и размеры фрагментов |
| 2 | Векторный поиск, гибридный поиск и реранкинг |
| 3 | Ответы разных LLM с RAG и без документов |
| 4 | Модели эмбеддингов BGE-M3 и multilingual-E5-large |

В конфигурацию включены шесть моделей семейств Qwen, Gemma и Ministral.
Ответы сохраняются отдельно от их оценки моделью-судьёй; прерванные запуски
можно продолжать. Инструкции и параметры приведены в
[руководстве](local_rag_service/TECHNICAL_GUIDE.md).

Подготовлено 90 вопросов с эталонными ответами по 15 документам.
Автор проекта сообщил о проверке ответов с преподавателями; это отражено
в статусах разметки. Исходные лекции не включены в репозиторий:
для воспроизведения этого набора экспериментов нужен соответствующий корпус.

## Статус

Реализованы RAG-пайплайн, API, терминальный чат и скрипты экспериментов.
На кластере проверен полный запрос по трём лекциям с Qwen 3.5 9B.
Локально пройдены 40 автоматических тестов. Полные сравнительные эксперименты
на 15 документах ещё не проведены; качество всех выбранных моделей не подтверждено.
